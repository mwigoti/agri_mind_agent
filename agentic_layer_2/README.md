# AgriMind Layer 2

Layer 2 is the agent orchestration and review API. It consumes the custom MCP gateway in `../mcp_server`, and the documented borrowed SQLite MCP server; it does not query platform tables or implement yield prediction.

## Run the local synthetic demonstration

Python 3.11–3.13 is recommended. From the repository root, create a virtual environment, install `layer_2/requirements.txt`, copy `layer_2/.env.example` to `.env`, set `API_BEARER_TOKEN` and a reviewer token, then start with:

```bash
python -m layer_2
```

The default `DEMO_MODE=true` uses only the clearly labelled, hard-coded synthetic fixtures in `synthetic.py`; it does not establish live model, database, satellite, or MCP integration. Check `GET /health`, start an analysis with `POST /api/advisories`, review it with the token mapped in `REVIEWER_TOKENS` via `POST /api/advisories/{thread_id}/decide`, and inspect `GET /api/demo/ranking`. API calls require `Authorization: Bearer <API_BEARER_TOKEN>`; the decision endpoint requires an officer-specific bearer token. The outbound payload is simulated and has no real destination.

For local review requests, use JSON such as `{"plot_id":"KE-001"}` and `{"verdict":"APPROVE"}`. The officer identity is derived from the server-side token map and never trusted from request JSON.

## Full MCP and hosted-model integration

Set `DEMO_MODE=false`, configure `HF_TOKEN`, set the model/provider settings, and install the optional upstream dependencies with `pip install -r layer_2/requirements-integration.txt`. Configure the database variables required by `mcp_server/README.md`. The service launches child processes through stdio: `python -m mcp_server.server` and the documented `mcp-server-sqlite` command. It discovers both servers' tool lists and validates call arguments against discovered schemas. The model is hosted by Hugging Face Inference Providers; weights are not downloaded locally. Synthetic task records only should be sent to an external provider.

This environment has not verified remote inference or actual upstream database availability. The custom MCP README documents its current tool contracts. Its status and telemetry tools describe numeric plot IDs while the prompt's paper uses KE-prefixed identifiers; resolve that mismatch in the upstream contract before running real integration. The history server is discovered and required at startup, but history is not currently included in the recommendation because the custom gateway provides no matching history-to-plot mapping contract.

## Persistence and safety

LangGraph uses its SQLite checkpointer at `CHECKPOINT_PATH`; audit events append to `AUDIT_PATH`. `/api/advisories/{thread_id}/decide` requires a reviewer token. No action is accepted unless the checkpoint is paused at `PENDING_APPROVAL`. A decision timestamp is generated by the service. Approval only returns a simulated payload; no SMS or other external action exists. Keep both SQLite files on persistent storage in deployment and protect them as operational records.

The local API token and reviewer tokens are demo authentication, not a replacement for platform SSO, role-based authorization, rotation, TLS termination, or an identity provider. Do not expose this demo service publicly.
